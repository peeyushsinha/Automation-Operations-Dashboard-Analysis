## Automation Operations Dashboard

An interactive **Power BI dashboard** built to monitor automation operations and analyze Process/Sub-Process performance using a linked, refreshable spreadsheet.

### Key Features

* **Power Query** data cleaning, quality checks, data-type validation, and transformation.
* Dedicated **Date Table with relationships** for date-based analysis.
* **DAX measures** for Total Cases, Resolved Cases, Failures, Skips, and Efficiency %.
* KPI Cards and an **Efficiency % Gauge** for operational monitoring.
* Dynamic **Process, Sub-Process, and Date slicers**.
* Workload and failure trend analysis.
* **Top-N failed Sub-Process** analysis.
* Detailed Process/Sub-Process **Matrix** with counts, percentages, and conditional formatting.
* **Dynamic refresh capability** so updated spreadsheet data can flow into the dashboard after refresh.

### Tech Stack

**Power BI | Power Query | DAX | Spreadsheet | Data Modeling | Data Visualization**

### Dashboard Flow

`Spreadsheet → Power Query → Data Model → Date Table → DAX Measures → Visualizations → Refreshable Dashboard`
